# Contributing to the SpecOps Skills Directory

Thank you for your interest in contributing to the SpecOps community skills directory. This project curates links to externally hosted AI agent instruction sets (skills) that follow the [SpecOps methodology](https://spec-ops.ai).

## How to Add a Skill

1. **Host your skill publicly.** Your skill should live in a public GitHub repository as a `SKILL.md` file (or similar Markdown format).

2. **Open a PR** that adds a row to the appropriate category table in [README.md](README.md). Each entry needs:
   - **Link** — URL to the `SKILL.md` file in your repository
   - **Description** — one sentence summarizing what the skill does
   - **Author** — link to the repository containing the skill

3. **Choose the right category.** Place your skill in the table that best fits:
   - **Spec-Driven Development Workflow** — general SpecOps workflow and setup
   - **Analysis & Planning** — extracting specifications from existing code
   - **Specification Generation** — converting analysis into implementation specs
   - **Verification & Auditing** — hardening specs and checking conformance
   - **Testing** — generating tests from specifications
   - **Orchestration** — coordinating multi-target pipelines

   If no existing category fits, propose a new one in your PR description.

## What Makes a Good Skill

- **Human-authored.** Skills should be written by people with domain expertise, not generated by AI.
- **Focused.** 2–3 targeted modules outperform broad documentation packages. Scope your skill to a specific class of tasks.
- **Tested.** Validate your skill against real code with multiple AI agents before submitting.
- **Well-documented.** Include clear purpose, examples, and output format so others can use it without your help.
- **Permissively licensed.** Skills should be public domain or use a permissive open source license (MIT, Apache, etc.) to ensure maximum reuse.

## Suggesting a New Category

If your skill doesn't fit an existing category, open an issue describing:
- The proposed category name
- What types of skills it would contain
- Why existing categories don't cover it

## Reporting Issues

If a linked skill is broken, outdated, or no longer maintained, open an issue with:
- The skill name and link
- What's wrong (404, outdated content, etc.)

## Code of Conduct

Be respectful and collaborative. This directory serves a broad community of practitioners across government, civic tech, and the private sector. Focus on sharing knowledge that helps others modernize legacy systems effectively.
